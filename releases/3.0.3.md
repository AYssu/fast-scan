# FastScan 3.0.3 更新日志

本次更新以兼容性与稳定性修复为主。

## 修复

- 修复部分 Root 环境下能检测到 Root、执行命令却提示找不到 su 的问题，兼容不同的 su 安装位置。
- 修复进程校验过程中，页面短暂失焦、恢复后反复触发校验，导致界面闪动、难以切换进程的问题；真正进入后台后返回仍会重新确认进程状态。
- 进程查询未及时完成时，支持主动重新获取进程，并中断旧查询，避免只能等待。
- 修复 SELinux 关闭、进程安全上下文为空时，运行应用列表可能为空的问题。
- 修复第三方内核读取库在调试输出前后附带日志，导致指针调试无法解析 JSON 结果的问题；保留链路校验与大整数精度。
- 修复原生库直接从 APK 映射时，模块列表可能无法识别对应 .so 模块的问题，提高模块选择和指针扫描兼容性。
- 修复小屏幕、横屏或输入法弹出时，模块选择窗口底部确认按钮可能被挤出屏幕的问题。

## 优化

- 进程、模块、文件列表、过滤候选查询及指针调试复用 libsu 的 Root 会话，减少重复启动 su；支持独立任务并发、取消及超时处理，会话失效后自动重建。
- 终端扫描保留独立 PTY 会话，维持原有终端交互方式。
