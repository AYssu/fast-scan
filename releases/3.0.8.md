# FastScan 3.0.8 更新日志

## 新增功能

- 设置新增主题选择：跟随系统、深色、浅色，立即生效并自动保存，主窗口与悬浮窗共用。

## 优化改进

- 调整页面布局、底部导航及切换体验，优化悬浮窗操作。
- 扫描模式、位数、主题等选项使用 Miuix 原生下拉，统一输入框、开关、菜单与加载进度样式。
- 扫描高级选项增加填写说明，错误格式在提交时提示，恢复输入框标签动效。
- 首页最近任务使用竖排布局，公告改为右上角通知入口，支持三天不提醒。
- 登录并查询授权时自动保存配置，精简授权结果操作，诊断和查询详情置底。
- 统一自动偏移输入框高度，淡化分隔线，优化输出路径刷新图标。
- 精简安装包，减少无用代码与资源。
- 终端配色适配浅色与深色主题，优化输出边距与结果路径显示。
- 内存范围统一移至“进程与模块”页，支持多选、全选及恢复默认，扫描页显示当前范围摘要。
- 统一目标进程与读取器状态，减少重复校验和无关操作触发的刷新。
- 长任务增加阶段、耗时与结果状态提示，明确停止及异常中断后的文件状态。
- 支持选择默认或自定义服务提供商。

## 问题修复

- 修复进程选择列表偶发无法打开及目标状态反复刷新的问题。
- 指针调试补充起始地址设置，优化数值类型多选与文件类型显示。

## 配套文件

- Pointer Chain Test 更新至 1.9，增加独立服务进程与对应链条，便于测试子进程选择和读取。
- C++ 模板迁移为 libfs 0.1.0：提供 Android arm64-v8a、x86_64 静态库、头文件及模块/读取示例，移除 libSea3 与旧接口。
- 当前目录仅保留最新 APK；历史版本请从 GitHub Releases 获取。内核驱动与 Lua 模板沿用现有文件。
