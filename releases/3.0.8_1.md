# FastScan 3.0.8_1 更新日志

交付标识为 3.0.8_1；软件内部版本仍为 3.0.8（版本码 3000010），扫描核心内部版本不变。

## 问题修复

- 修复子进程默认输出目录在部分真机上无法写入文件的问题。主进程和子进程统一保存到主包名目录，文件编号递增。
- 对比、过滤和格式化的默认文件目录同步归并到主包名，便于统一选择扫描结果；实际扫描目标仍是所选子进程。

## 配套模板

- libfs 更新至 0.1.1，用户模板改为 main.cpp，包名只初始化一次，可自由添加多组模块与偏移链；模块范围直接填写 Xa、Cd、Cb。
- 模板使用读写器实例动态注入，可替换 Syscall、Pread 或自定义驱动，后面的模块与链条用户代码无需更改。
- 提供 lsp64 单次解引用、read_pointer 多链条读取、int/float/double 读写、32/64 位指针与负偏移处理，保留独立实例读写及自定义读取器接入。
- Pointer Chain Test 1.9、扫描核心及驱动沿用 3.0.8。

本修复包已审核通过，按 v3.0.8_1 标签发布。
