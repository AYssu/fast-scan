# FastScan 3.0.6 更新日志

## 新增功能

- 新增应用更新检查，启动及设置页均可获取新版本信息和更新公告。
- 发现新版本后显示不可取消的更新弹窗，支持下载进度、失败重试和系统确认安装。
- 安装前校验包名、签名与版本，避免安装错误或旧版本的安装包。

## 优化改进

- 悬浮球改为更小的应用图标，按屏幕尺寸调整大小。
- 悬浮球与悬浮窗切换增加形变展开、收起动画。
- 关闭悬浮窗入口移至悬浮设置页，右上角仅保留收起，减少误触。
- 更新界面隐藏下载来源，仅展示版本、公告和下载进度。

## 问题修复

- 修复开启悬浮窗时因界面生命周期初始化顺序导致的崩溃。
- 改善更新信息包含空字段时的解析，下载失败不误报为最新版本。

## 配套文件与验证

- 使用 PackageInstaller 安装会话，安装仍由用户在系统界面确认；Android 8 及以上按需引导安装授权。
- 已在 Android 11 模拟器验证安装确认界面与取消后重试；未覆盖所有系统和厂商，未用真实新版本完成自更新覆盖安装。
- Pointer Chain Test 1.7、驱动及动态基址模板沿用 3.0.5。
