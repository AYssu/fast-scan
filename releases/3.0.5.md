# FastScan 3.0.5 更新日志

本次更新新增悬浮窗与悬浮球，并优化横竖屏操作和结果显示。

## 扫描修复（包含未单独发布的 3.0.4）

- 修复第三方框架中扫描临时缓存创建失败导致的 `FORTIFY: fileno: null FILE*` 崩溃。
- Root 与非 Root 共用缓存处理：优先使用应用提供的可写缓存目录，未配置时保留系统临时文件方式。
- 缓存创建、写入、扩容或映射失败时明确报错，完善资源释放和容量检查。

## 新增

- 首页新增悬浮窗入口，授权悬浮权限后可在其他应用上方操作 FastScan。
- 悬浮窗支持主页、基础、扫描、对比、过滤、格式化、调试、MCP 和设置页面。
- 支持拖动标题栏移动、右下角拖拽缩放、悬浮窗与悬浮球切换；任务可在收起后继续运行。
- 悬浮界面支持文件选择、地址导入、日志导出、权限跳转及嵌套弹窗。

## 界面优化

- 横屏导航位于左侧，竖屏导航位于顶部；按窗口实际宽度适配布局，保留系统字体缩放。
- 调整对比、过滤、格式化和调试的表单分组，减少孤立半宽区块与大片空白；调试编辑区使用完整宽度。
- 宽窗口设置页使用两列连续分组，修复长规则列表造成的大面积空白。
- 软键盘覆盖悬浮窗下半部分，保持窗口位置和尺寸；内容区与弹窗按键盘避让。
- 横屏任务窗将标题、状态、耗时与关闭/取消合为一行，扩大输出区域；竖屏保留上下布局，终端字体保持 9sp。
- 修复分数屏幕密度下双列意外换行、大字体导航提示导致持续重排等问题。

## 验证与配套文件

- 已在 Android 11 x86_64 模拟器验证横竖屏、窗口缩放、键盘、文件选择、弹窗及收起恢复。
- 本次新增悬浮功能尚未在全部真机、系统和第三方框架中验证。
- 完整包包含 Pointer Chain Test 1.7 正式构建，启用代码与资源裁剪，保留 M3 界面、JNI 和双架构支持，扫描核心、配套驱动与动态基址模板沿用 3.0.4。

- 测试软件新增 APK 内加载与独立 SO 文件加载两组各 1～4 级链条，用于验证 `base.apk` 和具名 `.so` 两种模块映射；外部取址接口支持 `group=apk/file`，不传时兼容 APK 组。
- 测试软件修复长按后松手可能误点复制弹窗按钮的问题，保留原有点击改值与长按复制行为。
