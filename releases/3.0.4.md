# FastScan 3.0.4 更新日志

本次更新修复第三方框架环境中的扫描临时缓存问题。

## 修复

- 修复部分第三方框架中，非 Root 扫描在第 0 层报 `FORTIFY: fileno: null FILE*`、退出码 -6 的崩溃。
- 扫描临时缓存优先使用应用提供的可写缓存目录；未配置时保留系统临时文件方式。Root 与非 Root 共用此逻辑。
- 临时缓存创建、写入、扩容或映射失败时明确报错，避免创建失败被当作空指针池继续扫描。
- 完善缓存句柄与映射的释放，并检查容量溢出及空缓存文件。

## 验证

- FY 框架内实际非 Root 扫描通过：6 层、偏移 2000，完成输出 1,786,543 条链。
- 临时缓存故障注入及相关扫描回归测试 10/10 通过。

不同框架与读取器仍需按实际环境验证。驱动和动态基址模板沿用上一版本。

## 配套测试软件

- 完整包新增 Pointer Chain Test 1.5（包名 com.ayssu.chainlab），提供固定的 1～4 级 JNI 指针链。
- 链路以 Cd 段为基址显示；点击随机改变整数，长按复制地址、值或链路，便于验证扫描。
