# FastScan 3.0.9_1 更新日志

交付标识为 3.0.9_1，软件内部版本仍为 3.0.9（版本码 3000011），沿用现有签名。

## Bug 修复

- 修复 32 位低地址指针被采集阈值过滤、导致相关链路遗漏的问题。
- 恢复每次启动首次进入主页时自动弹出非空公告；关闭后本次不重复弹出，三天不提醒与铃铛手动查看继续有效。

## 配套说明

- 包含 3.0.9 的 GG Lua、C++ 工程和可执行文件生成功能。
- 更新扫描核心、操作手册、README 和发布清单；测试工具、libfs、驱动沿用当前配套版本。
- 从较新基础版本发布开始，旧版本仅保留基础 Release，删除旧版本修复包 Release 及附件；保留历史标签与更新说明。
