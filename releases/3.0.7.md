# FastScan 3.0.7 更新日志

## 新增功能

- 对比与过滤支持自定义匹配上限，默认 3000 万条。
- 配套 Pointer Chain Test 更新至 1.8，新增大内存和大量真实指针测试场景，方便验证扫描效果。

## 优化改进

- 优化大规模指针扫描，降低内存占用，提升扫描效率。
- 优化扫描、对比、过滤的终端显示，增加颜色、进度及预计剩余时间。
- 模块链路显示增加内存范围标签，更方便区分 Cd、Cb、Cdro 等区域。

## 问题修复

- 改善部分内存读取不完整或遇到不可读页时的处理，减少扫描遗漏。

## 配套文件

- 完整包包含 FastScan 3.0.7 和 Pointer Chain Test 1.8。
- 测试工具保留两组各 1～4 级固定路径，点击随机改值，长按复制地址、值或链路。
- 驱动及动态基址模板沿用 3.0.6，支持情况以设备实际测试为准。
