# FastScan 3.0.2 更新日志

## 新增

- 新增终端「隐藏模式」，通过应用私有目录入口启动终端，保留实时输出。默认仍为「系统默认」。

## 优化与修复

- 终端模式改为下拉单选，移至路径设置下方，并补充两种模式的说明。
- 统一存储权限申请流程，修复缺少存储权限时 MCP 无法正常启动的问题；授权后自动继续本次启动。
- 完善 MCP 后台运行与权限引导，仅提示尚未满足的项目，支持按需开启息屏保持运行。
- 优化 MCP 与界面的参数同步，调整目标进程、读取器和扫描参数时减少重复配置与服务重启。
- 增强配置保存可靠性，降低写入失败或并发读写造成配置损坏的风险。
- 整理页面与状态管理逻辑，保持原有操作流程和扫描默认参数。

> 隐藏模式仅改变终端访问入口，底层仍为系统 PTY，不保证规避所有检测。
